# Геонапоминалка

Android-приложение (Kotlin, MVVM + Repository) для напоминаний, привязанных к точке на карте.
Реализация соответствует ТЗ: создание задач долгим тапом по карте, foreground-сервис
геолокации, уведомления с кнопками «Выполнено»/«Отложить», менеджер задач, настройки.

## Как открыть и собрать

1. Откройте папку проекта в Android Studio (Koala/2024.1+ рекомендуется).
2. Скопируйте `local.properties.example` в `local.properties` (нужен только `sdk.dir`,
   Android Studio обычно проставляет это сама). API-ключ карты НЕ требуется.
3. Дайте Gradle синхронизироваться (скачает зависимости из google()/mavenCentral()).
4. Запустите конфигурацию `app` на устройстве/эмуляторе.

## Карта

Используется **OSMDroid** (OpenStreetMap) — бесплатно, без API-ключа и привязки карты.
- Обычная схема — тайлы Mapnik (OSM).
- "Спутник" — публичные тайлы Esri World Imagery (тоже бесплатные, без ключа).
- FusedLocationProviderClient (получение текущих координат) из Google Play Services
  остаётся — это отдельный бесплатный компонент, ключ карт для него не нужен;
  на устройствах без Play Services эту часть нужно будет заменить на LocationManager.
- Тайлы кэшируются в `getExternalFilesDir("osmdroid_tiles")`.

## Что реализовано

- **data/** — Entity `Reminder`, Room DAO/Database, `ReminderRepository`,
  `SettingsRepository` (DataStore: тема, звук, вибрация, интервал, тип карты).
- **service/LocationForegroundService** — FusedLocationProviderClient, проверка расстояния
  до каждой активной задачи, антиспам-логика (cooldown 10 мин + гистерезис выхода из зоны).
- **receiver/NotificationActionReceiver** — обработка кнопок уведомления без открытия приложения.
- **ui/MainActivity** — карта на весь экран, бургер-меню, долгий тап → создание,
  тап по маркеру → удаление, зум, поиск адреса (Geocoder), переключение типа карты.
- **ui/TaskEditActivity** + **MapPickerActivity** — создание/редактирование, координаты
  только для чтения, смена точки через отдельный экран карты.
- **ui/TaskListActivity** — список активных/выполненных задач.
- **ui/SettingsActivity** — тема, интервал опроса, звук (RingtoneManager), вибрация, сброс данных.
- **GeoApp** — наблюдает `Flow<Int>` количества активных задач и запускает/останавливает
  foreground-сервис при переходе 0↔1 (п.1.6 ТЗ).

## Известные упрощения (можно доработать)

- Иконки — простые векторные заглушки, стоит заменить на дизайн-иконки.
- "Спутник" на Esri — публичный эндпоинт без гарантированного SLA; для продакшена
  лучше взять платный тайл-провайдер (Mapbox/MapTiler) или официальный Esri-ключ.
- Поиск адреса использует deprecated синхронный `Geocoder.getFromLocationName` —
  для API 33+ стоит перейти на асинхронную версию с колбэком.
