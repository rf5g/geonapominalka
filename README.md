# Геонапоминалка

Android-приложение (Kotlin, MVVM + Repository) для напоминаний, привязанных к точке на карте.
Реализация соответствует ТЗ: создание задач долгим тапом по карте, foreground-сервис
геолокации, уведомления с кнопками «Выполнено»/«Отложить», менеджер задач, настройки.

## Как открыть и собрать

1. Откройте папку проекта в Android Studio (Koala/2024.1+ рекомендуется).
2. Скопируйте `local.properties.example` в `local.properties` (нужен только `sdk.dir`,
   Android Studio обычно проставляет это сама). API-ключ карты НЕ требуется.
3. Дайте Gradle синхронизироваться (скачает зависимости из google()/mavenCentral()).
4. Запустите конфигурацию `app` на устройстве/эмуляторе.

## Карта

Используется **OSMDroid** (данные OpenStreetMap) — бесплатно, без API-ключа и привязки карты.
- Обычная схема — тайлы **CARTO Basemaps** (light_all), а не штатный `TileSourceFactory.MAPNIK`:
  прямой `tile.openstreetmap.org` активно блокирует запросы из приложений (403 Forbidden) —
  их публичный сервер не предназначен для встраивания, только для эпизодического
  браузерного использования. CARTO — тоже бесплатно, без ключа, но без такой блокировки.
- "Voyager" — более цветной/подробный стиль того же CARTO.
- "Спутник" — публичные тайлы Esri World Imagery (тоже бесплатные, без ключа).
- "Гибрид" — тот же спутник Esri + полупрозрачный слой подписей CARTO поверх (дороги, названия) —
  собственного гибридного режима у бесплатных провайдеров нет, поэтому это композиция двух тайлов.
- Все источники — в `util/TileSources.kt`; стиль синхронизирован между кнопкой на карте
  и разделом «Стиль карты» в настройках через один и тот же ключ `mapType` в `SettingsRepository`.
- **Про номера домов**: у CARTO нет отдельного слоя с номерами домов ни в одном из стилей —
  это общее ограничение упрощённых бесплатных базовых карт. Пробовали зеркало классического
  OSM Standard на серверах Wikimedia (`maps.wikimedia.org`), но оно оказалось нестабильным
  (тайлы не грузятся), поэтому такой пункт убран из списка стилей. Если номера домов
  принципиально нужны — единственный практичный путь это платный тайл-провайдер с ключом
  (у Mapbox/MapTiler/Stadia Maps есть щедрый бесплатный тариф без требования карты, в
  отличие от Google).
- FusedLocationProviderClient (получение текущих координат) из Google Play Services
  остаётся — это отдельный бесплатный компонент, ключ карт для него не нужен;
  на устройствах без Play Services эту часть нужно будет заменить на LocationManager.
- Тайлы **кэшируются на диске** (`getExternalFilesDir("osmdroid_tiles")`) — при повторном
  открытии уже просмотренной области тайлы берутся из кэша, а не скачиваются заново;
  сервер нагружается в основном при первом посещении новой области.
- Поиск адреса (`Geocoder`) сначала ищет в bounding box вокруг последней известной
  геопозиции пользователя (±~1° широты/долготы), чтобы не путать одноимённые улицы
  в разных регионах; если в области ничего не нашлось — ищет без ограничения.
- Курсор «моё местоположение» и маркеры — кастомные векторные иконки для контраста
  на светлых стилях карты (штатные иконки osmdroid/Material слишком блёклые):
  курсор — `#E65100`, булавки задач — красные, булавка результата поиска — синяя.

## Что реализовано

- **data/** — Entity `Reminder`, Room DAO/Database, `ReminderRepository`,
  `SettingsRepository` (DataStore: тема, звук, вибрация, интервал, тип карты).
- **service/LocationForegroundService** — FusedLocationProviderClient, проверка расстояния
  до каждой активной задачи, антиспам-логика (cooldown 10 мин + гистерезис выхода из зоны).
- **receiver/NotificationActionReceiver** — обработка кнопок уведомления без открытия приложения.
- **ui/MainActivity** — карта на весь экран, бургер-меню, долгий тап → создание,
  тап по маркеру → удаление, зум, поиск адреса (Geocoder), переключение типа карты.
- **ui/TaskEditActivity** + **MapPickerActivity** — создание/редактирование, координаты
  только для чтения, смена точки через отдельный экран карты.
- **ui/TaskListActivity** — список активных/выполненных задач.
- **ui/SettingsActivity** — тема, интервал опроса, звук (RingtoneManager), вибрация, сброс данных.
- **GeoApp** — наблюдает `Flow<Int>` количества активных задач и запускает/останавливает
  foreground-сервис при переходе 0↔1 (п.1.6 ТЗ).
- **Боковое меню → «Закрыть совсем»** — принудительно останавливает сервис геолокации
  и завершает процесс приложения (`killProcess`), независимо от количества активных
  задач. В отличие от обычного «Выход» (просто закрывает экраны, сервис продолжит
  работать в фоне, если есть активные задачи — это штатное поведение), эта кнопка
  гарантированно ничего не оставляет висеть в фоне. Предупреждает, если есть активные
  задачи — уведомления по ним не придут, пока приложение не откроют снова.
- **Боковое меню → «Консоль»** (`util/AppLogger.kt`, `ui/LogActivity.kt`) — визуальный
  журнал работы сервиса геолокации в реальном времени: интервал опроса, полученные
  координаты, вход/выход из геозон, отправленные уведомления. Хранится в памяти
  процесса (до 500 последних записей), обновляется живьём через `StateFlow`. Кнопки
  и прочие UI-действия туда намеренно не попадают — только геоданные.
- Карта при запуске приложения центрируется на последней известной геопозиции
  пользователя (если разрешение выдано), а не на дефолтных координатах — координаты
  из `setupMap()` используются только как запасной вариант, пока геопозиция не получена.

## Известные упрощения (можно доработать)

- Иконки — простые векторные заглушки, стоит заменить на дизайн-иконки.
- "Спутник" на Esri — публичный эндпоинт без гарантированного SLA; для продакшена
  лучше взять платный тайл-провайдер (Mapbox/MapTiler) или официальный Esri-ключ.
- Поиск адреса использует deprecated синхронный `Geocoder.getFromLocationName` —
  для API 33+ стоит перейти на асинхронную версию с колбэком.
